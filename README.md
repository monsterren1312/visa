# Immigration USA Telegram Bot

Автоматически публикует новости об иммиграции, грин-картах и визах США на
русском языке в Telegram-канал. Источники — RSS-ленты (Immigration Impact,
Boundless, CitizenPath, Murthy Law Firm). Перевод и переписывание текста —
через Anthropic API (Claude). Публикация — через Telegram Bot API.
Запускается по расписанию через GitHub Actions, без сервера.

Структура полностью повторяет la-news-bot — просто другие источники,
подпись канала и фильтрация по ключевым словам (иммиграция/визы/USCIS),
чтобы не публиковать нерелевантные посты из тех же блогов.

## Что нужно сделать один раз перед запуском

### 1. Создать новый Telegram-канал

- Создай канал в Telegram (например "Иммиграция и визы США").
- Сделай его публичным и задай username (например `@us_immigration_news`) —
  либо оставь приватным и узнай числовой `chat_id` через @userinfobot
  (перешли ему любой пост из канала).
- Добавь бота **@aipostbot** админом в этот канал с правом публикации сообщений.

### 2. Узнать TELEGRAM_CHAT_ID

- Если канал публичный — можно использовать сам username в формате `@us_immigration_news`.
- Если приватный — нужен числовой ID вида `-1001234567890` (получить через @userinfobot).

### 3. Узнать TELEGRAM_BOT_TOKEN

- Напиши @BotFather в Telegram → `/mybots` → выбери @aipostbot → `API Token`.
- Скопируй токен (выглядит как `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`).

### 4. Получить ANTHROPIC_API_KEY

- console.anthropic.com → Create API key (обычный статичный ключ, не identity-based).
- Тот же ключ можно переиспользовать из других твоих ботов (CryptoMedia, LA News).

### 5. Указать ссылку на канал (для подписи в конце постов)

- Например `https://t.me/us_immigration_news` (публичный) или инвайт-ссылка (приватный).

## Настройка репозитория на GitHub

1. Создай новый **приватный** репозиторий на github.com.
2. Залей туда все файлы из этой папки (bot.py, requirements.txt,
   .github/workflows/post.yml, state/seen.json, README.md) — сохраняя
   структуру папок как есть.
3. Зайди в **Settings → Secrets and variables → Actions → New repository secret**
   и добавь четыре секрета:

   | Имя секрета          | Значение                                                 |
   | --------------------- | -------------------------------------------------------- |
   | `TELEGRAM_BOT_TOKEN`  | токен от @BotFather                                       |
   | `TELEGRAM_CHAT_ID`    | `@us_immigration_news` или числовой chat_id                |
   | `ANTHROPIC_API_KEY`   | ключ с console.anthropic.com                               |
   | `CHANNEL_URL`         | `https://t.me/us_immigration_news` (или инвайт-ссылка)     |

4. Перейди во вкладку **Actions** репозитория — GitHub может попросить
   подтвердить включение Actions для этого репозитория.

## Как проверить, что всё работает

1. Во вкладке **Actions** найди workflow **"Immigration USA Autoposter"**.
2. Нажми **"Run workflow"** — это запустит бота вручную, не дожидаясь расписания.
3. Открой запуск, посмотри логи — там видно, сколько новостей найдено,
   сколько отфильтровано как нерелевантные, что опубликовано.
4. Проверь сам канал в Telegram — должны появиться 1-2 новых поста.

После этого бот будет запускаться сам каждые 30 минут (расписание в
`.github/workflows/post.yml`), максимум 1 пост за запуск (регулируется
переменной `MAX_POSTS_PER_RUN`, аналогично la-news-bot).

## Как добавить/убрать источники новостей

Открой `bot.py`, найди список `RSS_SOURCES` в начале файла — добавь или
убери словарь с `"name"` и `"url"`. Изменения подхватятся при следующем
запуске автоматически.

## Фильтрация по теме

В отличие от la-news-bot, здесь источники — общие юридические/иммиграционные
блоги, которые иногда пишут не только про визы/грин-карты. Список
`FILTER_KEYWORDS` в `bot.py` отсеивает нерелевантные посты — если решишь
добавить более широкий источник (например общий юридический блог), просто
проверь, что нужные слова там есть в `FILTER_KEYWORDS`.

## Защита от повторов

Бот хранит в файле `state/seen.json` ссылки на уже опубликованные новости
и хэши заголовка+описания. GitHub Actions сам коммитит обновлённый файл
обратно в репозиторий после каждого запуска.

## Если что-то не публикуется

Смотри логи в вкладке Actions:

- Бот не добавлен админом в канал → ошибка от Telegram API в логах.
- Неверный `TELEGRAM_CHAT_ID` (забыли минус перед числовым ID) → "chat not found".
- Закончился баланс на Anthropic API → пост для этой новости пропускается,
  бот не падает целиком.
- Мало новых постов → возможно, за последний интервал в источниках не было
  ничего по теме иммиграции — это нормально, не все посты в этих блогах
  релевантны.
